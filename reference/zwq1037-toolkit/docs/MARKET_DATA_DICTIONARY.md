# Market 数据字典与处理规则

## 记录范围

本文件区分四类依据：

- **官方定义**：来自比赛数据说明。
- **文件事实**：直接来自训练 market 的 schema。
- **小样本证据**：来自样本 ID 0～4，共 838 行；需要在扩大数据范围时复核。
- **处理决定**：当前项目为了避免破坏数据含义而采用的规则。

## 行与键

| 项目 | 当前认识 | 依据 |
|---|---|---|
| 一行 market | 预测时点前某个相对时刻的等间隔市场汇总 | 官方定义 |
| `sample_id` | 一段 market 序列与 label 的对齐键 | 文件事实与小样本对齐 |
| `seconds_before_predict` | 距离预测时点的秒数；越小越接近预测时点 | 官方定义与小样本证据 |
| label 对应关系 | market 中一个 `sample_id` 的多行对应 label 中一行 | 小样本证据 |
| 样本长度 | 不假设固定 200 行；5 个样本为 107～200 行 | 小样本证据 |

## 字段

| 字段 | dtype | 含义 | 缺失情况与状态 |
|---|---|---|---|
| `sample_id` | `int32` | 样本标识 | 小样本无缺失 |
| `seconds_before_predict` | `float32` | 距离预测时点的秒数 | 小样本无缺失 |
| `transaction_avgprice` | `float32` | 当前 market 时间段内的平均成交价 | 小样本有 251 个缺失，均对应零成交 |
| `transaction_volume` | `int32` | 当前时间段的成交量 | 小样本无缺失；可为 0 |
| `transaction_count` | `int32` | 当前时间段的成交次数 | 小样本无缺失；可为 0 |
| `ask_price_1` | `float32` | 第一档卖价 | 小样本无缺失 |
| `ask_volume_1` | `int32` | 第一档卖量 | 小样本无缺失 |
| `bid_price_1` | `float32` | 第一档买价 | 小样本无缺失 |
| `bid_volume_1` | `int32` | 第一档买量 | 小样本无缺失 |
| `ask_price_2` | `float32` | 第二档卖价 | 小样本无缺失 |
| `ask_volume_2` | `int32` | 第二档卖量 | 小样本无缺失 |
| `bid_price_2` | `float32` | 第二档买价 | 小样本无缺失 |
| `bid_volume_2` | `int32` | 第二档买量 | 小样本无缺失 |

## 已验证关系

在样本 ID 0～4 的 838 行中：

```text
transaction_avgprice.isna()
```

与：

```text
transaction_count == 0
```

逐行完全一致，共 251 行。这支持“没有成交时平均成交价没有定义”的推断，但尚未对完整训练数据证明。

典型相邻 market 间隔约为 3 秒。样本 1 和 2 存在较多超过 4.5 秒的空档，因此当前流程不假设每个样本严格等长。

## 当前处理决定

| 问题 | 当前决定 | 原因 |
|---|---|---|
| 无成交行 | 保留整行 | “没有成交”仍是市场状态 |
| `transaction_avgprice` 的 `NaN` | 原始与中间数据中保留 | 不制造假价格，不提前丢失缺失含义 |
| 是否有成交 | 可增加 `has_transactions = transaction_count > 0` | 给后续流程明确的 mask/指示信息 |
| LightGBM 输入 | 第一版允许保留缺失 | 树模型阶段再做对照实验 |
| 神经网络输入 | 保存 mask；填充值由训练流程决定 | 普通 Tensor 计算不能放任 `NaN` 传播 |
| 不等长序列 | 暂不补行 | 表格基线先聚合实际观测；序列模型阶段再设计 padding 和 mask |

## 仍待完整数据复核

- 零成交与平均成交价缺失是否在完整训练集、测试集都完全一致。
- 每个样本是否存在重复的 `seconds_before_predict`。
- 时间空档分布是否随月份发生明显变化。
- 测试集 schema、dtype 和缺失规则是否与训练集一致。
