# 项目教学计划

## 总体原则

本项目先建立“不会骗自己的验证”，再学习模型。前 10% 是跨比赛逐步形成的长期能力目标，不是本比赛的硬性名次要求；本项目第一目标是独立做出可信验证和有效提交。

每课仍遵循：给出本课配套阅读 → 讲清直觉与必要语法 → 最小例子 → 学习者完成核心小任务 → Codex 只检查运行 → 学习者修正 → 验收。

Python 不作为独立课程主线。新的语法和库接口在实际用到时解释；机器学习、深度学习和量化理论则通过每课指定教材章节进行系统补充。

完整的单课执行细节以 [TEACHING_WORKFLOW.md](TEACHING_WORKFLOW.md) 为准，课外资料选择以 [LEARNING_RESOURCES.md](LEARNING_RESOURCES.md) 为准，实时课程状态只以 [LEARNING_PROGRESS.md](LEARNING_PROGRESS.md) 为准。

## 阶段 0：资源、环境与赛题审查

学习内容：数据规模、Feather 文件、内存与磁盘、Kaggle 认证和本地/Kaggle Notebook 分工。

产物：资源检查结果和本地/Kaggle Notebook 运行方案。

## 阶段 1：标签与预测目标

学习内容：标签表的一行代表什么；`month`、`sample_id`、`target` 的角色；回归目标；标签的规模、月份和分布。

产物：标签数据字典和可重复运行的标签检查脚本。

## 阶段 2：可靠的时间验证

学习内容：点积、向量长度和余弦相似度；随机划分为什么会泄漏；训练期与验证期之间的时间顺序；固定 forward validation，并为后续 walk-forward validation 建立基础。

产物：经过数字例子验证的本地余弦评分函数，以及固定且互不重叠的训练月份和验证月份。

## 阶段 3：安全读取并对齐 market 小样本

学习内容：时间戳、资产、事件流、等间隔序列；使用 pandas/PyArrow/Polars 查看 schema，并按列、月份或样本安全读取大文件；确认 market 与 label 的对齐键、时间步和缺失情况。

产物：只包含少量月份和样本的可重复 market 切片，以及 market 数据字典和对齐检查结果。

## 阶段 4：LightGBM 强基线

已有前置能力：上一项目已经学习并实际比较过决策树、随机森林、HistGradientBoosting、LightGBM 和 early stopping，也理解 boosting 由多棵树逐步修正而不是只保留最后一棵树。本阶段不重新讲这些模型的入门原理。

新增学习内容：把一段金融时间序列汇总成均值、波动率、最大值、最小值、首尾变化、样本长度和时间空档等表格特征；将每个 `sample_id` 变成一行；按月份做 forward validation；在大文件上安全生成特征；复用 LightGBM 与 early stopping 做可信对照实验。

产物：第一个可信的金融时间序列 LightGBM 验证分数。上一项目的模型与 early-stopping 模板直接复用，只亲手完成本项目新出现的序列聚合、时间验证和大数据流程。

## 阶段 5：PyTorch 与 MLP 过渡

学习内容：Tensor、Dataset、DataLoader、batch、训练循环、回归损失、验证模式和 GPU。MLP 用于把上一阶段的特征送入神经网络，重点是掌握 PyTorch 闭环。

产物：一个能训练、验证、保存和恢复的 MLP。

执行调整：基础训练循环掌握后，将原5I“验证循环”和5J“真实数据MLP”合并。直接复用62维聚合特征，先短试跑再全量；只新增PyTorch验证开关、Adam直觉及最佳参数保存，不重复训练已掌握的验证概念。恢复一致性与对照已纳入全量实验的教师诊断，不再单开5K；加载接口尚不视为学习者已掌握，在CNN保存与恢复时按需补讲。逐课状态仍仅记录在`LEARNING_PROGRESS.md`。

## 阶段 6：1D CNN 时间序列模型

学习内容：输入形状 `(batch, channels, time)`；卷积核如何发现局部价格/成交模式；池化、感受野和残差连接。

产物：market-only 1D CNN，并与 LightGBM 在同一时间划分上比较。

执行节奏：6A局部卷积、通道与前向shape；6B真实观测序列的截断/补齐、缺失标记与训练期标准化规则；6C用三个检查点依次完成磁盘映射小样本、全量缓存和mask-aware CNN训练，并复用训练/验证/保存模板，先试跑再正式对照。三个检查点仍属于同一课，目的是控制每次只引入1～2个新概念，不增加重复的CNN入门课。实际记录虽通常约3秒一次，却不严格落在统一格点且可能发生映射碰撞，第一版不冒充严格等间隔网格。感受野、残差等根据实际模型需求深化，不为覆盖术语而单独安排低价值重复练习。CNN使用逐时刻数据，与聚合表基线属于整套方案对照，不把分数变化全部归因于模型结构。

## 阶段 7：Transformer Encoder

学习内容：输入形状 `(batch, time, features)`；token/时间步、位置编码、自注意力、mask、Encoder block。这里学习的是数值时间序列 Transformer，不是聊天模型。

产物：market-only Transformer，并完成 CNN/Transformer 的公平对照实验。

## 阶段 8：多数据流与消融实验

学习内容：逐步加入 order 和 transaction；多分支编码；只改变一个主要变量；判断新增信息是否真正有效。

产物：market-only、+order、+transaction 的消融表。

## 阶段 9：融合与提交

学习内容：不同模型预测的尺度、加权融合、完整训练、批量推理、提交格式和 Kaggle 分数解释。

产物：至少一个可复现提交，以及本地分数与排行榜分数对照。

## 阶段 10：量化现实检查与复盘

学习内容：预测指标不等于可交易收益；手续费、滑点、冲击成本、仓位约束；哪些竞赛技巧能迁移到真实研究。

产物：项目报告、有效/无效实验和下一步学习方向。

## 资源预案

- 原始下载约 10 GB，但解压、缓存、特征和模型会继续占空间。本地完整实验建议预留至少 40–60 GB。
- 16 GB 内存可以从抽样和分块读取开始；32 GB 更从容。
- 首课检查 GPU 与 CUDA 后再确定深度模型 batch size。
- 若本机资源不足，代码仍在本地维护，大数据训练迁移到 Kaggle Notebook。
