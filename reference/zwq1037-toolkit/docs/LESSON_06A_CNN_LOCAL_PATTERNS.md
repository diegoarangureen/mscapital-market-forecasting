# 第6A课：CNN怎样沿时间寻找局部模式？

## 1. 这次改变的，不只是模型名字

上一课的MLP看到的是每个样本的62个聚合数。它不知道这段时间内的价格究竟是平稳上升，还是先跌后涨。

例如，两段价格：

```text
A：1 → 2 → 3 → 4
B：1 → 3 → 2 → 4
```

它们的均值都是2.5，起点和终点也相同，但中间的过程不同。只提供这些统计量，就无法还原中间的变化。

我们现在尝试保留逐时刻的数据，让模型自己寻找短时间内的变化模式。CNN（Convolutional Neural Network，卷积神经网络）是实现这个想法的一种方式。

注意：不是“MLP在数学上不能处理序列”。MLP也可以接收展开后的序列；我们此前的MLP只是没有获得这些信息。CNN额外引入了局部连接和共享权重的结构。

本课只掌握两件事：

1. 卷积核怎样沿时间滑动，用同一套权重计算不同位置。
2. 时间序列怎样摆成PyTorch需要的形状，并得到每个样本一个预测。

数据创建、池化和输出层代码已经提供。你只填写一个手算结果和两处核心代码。不训练玩具数据、不重写训练循环，也不要求CNN一定超过LightGBM。

## 3. 先把卷积想成一把滑动的小尺子

暂时只有一个特征，连续五个时刻的值是：

```text
输入：1，2，4，7，11
小尺子上的三个权重：-1，0，1
```

每次取连续三个数，对应乘权重再相加。先不加偏置，不在边界补数，每次移动一个位置：

```text
第一个窗口：[1，2，4]  →  -1×1 + 0×2 + 1×4  = 3
第二个窗口：[2，4，7]  →  -1×2 + 0×4 + 1×7  = 5
第三个窗口：[4，7，11] →  -1×4 + 0×7 + 1×11 = 7
```

所以输出是`[3, 5, 7]`。这把尺子在测“窗口末端相对起点涨了多少”。换一套权重，就会得到别的计算方式。

正式写成公式，核宽为3时：

$$
z_t=w_0x_t+w_1x_{t+1}+w_2x_{t+2}+b
$$

这里的$t$是窗口起点，$x$是输入，$w_0,w_1,w_2$是三个权重，$b$是偏置，$z_t$是这个窗口的输出。例如第一个窗口中，$t=0$、三个输入为1、2、4，权重为-1、0、1，偏置为0，输出就是3。

### 核心不是滑动动画，而是两个限制

- **局部连接**：这个输出只看连续三个位置，不一开始就混合整段数据。
- **共享权重**：移动到下一个窗口时，仍使用同一组`[-1, 0, 1]`，不是每个位置都有独立参数。

上面的权重是我为演示指定的。真正训练时通常随机初始化，再通过你已学过的`loss.backward()`和`optimizer.step()`学习。窗口滑动属于前向计算，本身不会更新权重。

在深度学习接口中，这个不翻转核的计算严格叫“互相关”，习惯上仍称卷积；本课按PyTorch实际计算方式理解，不必先纠结术语差别。

人话总结：**拿同一套可学习的小公式，检查序列中不同位置的短片段。** 如果这一句还不清楚，先问我，不急着写代码。

## 4. 一维不代表只能输入一个特征

假设每个时刻有三个特征：价格变化、买卖价差、成交活跃度。每个特征沿时间形成一条序列，称为一个输入通道（input channel）。

核宽为3时，一个输出会同时看“3个相邻时刻 × 3个输入特征”，也就是9个数，并用9个权重组合它们，再加偏置。这里说的是默认的普通卷积，不涉及分组卷积。

如果设置8个输出通道，就是学习8套这样的组合，输出8条响应序列；不是8棵树、8层网络，也不是8个预测目标。各通道共同服务于最终预测，不保证每条都能解释成一种明确的金融模式。

为什么叫1D？因为窗口只沿一条轴——时间——滑动。它仍然可以同时读取很多特征。

### 输入三个轴的含义

本课固定数据有2个样本，每个样本8个时刻，每个时刻3个特征。数据最初按下面方式组织：

| 排列 | shape | 解释 |
|---|---|---|
| 数据准备时 | `(2, 8, 3)` | 样本、时间、特征 |
| 交给Conv1d时 | `(2, 3, 8)` | 样本、通道、时间 |

三个轴都是从0开始编号。把通道放中间是接口约定，不是把时间打乱：一个通道里的时刻仍然从早到晚。

### `permute()`：调换轴，不是重新排序时间点

这是PyTorch Tensor的方法，已有`import torch`即可。写法是：

```python
# 每个参数是旧轴编号；按给定顺序组成新的轴排列。
# Each argument names an old axis in the desired new order.
new_tensor = old_tensor.permute(0, 2, 1)
```

`0, 2, 1`不是取第0、2、1个样本，而是：新第0轴用旧第0轴，新第1轴用旧第2轴，新第2轴用旧第1轴。输入是三维Tensor，返回也是Tensor。

最小例子：

```python
import torch

# 一个样本、两个时刻、每时刻两个特征。
# One sample, two time steps, and two features per step.
example = torch.tensor([[[1.0, 10.0], [2.0, 20.0]]])
reordered = example.permute(0, 2, 1)
print(reordered)
# tensor([[[1., 2.], [10., 20.]]])
```

原来每行是同一时刻的两个特征；现在每行是同一特征的两个时刻。即使shape碰巧一样，数值的对应关系也变了。

常见错误：用`reshape(2, 3, 8)`代替换轴。`reshape`按元素排列重组形状，不保证“同一特征的整条时间序列”被放在一起。`permute`返回共享原存储的视图，本课只读它、不原地改值，不必为此增加`.copy()`；Tensor也不是用DataFrame的`.copy()`接口。

## 5. `nn.Conv1d`：建立一层可学习的小尺子

来源：PyTorch的`torch.nn`，使用`from torch import nn`。`nn.Conv1d(...)`是创建层对象，`layer(inputs)`才执行前向计算，和你用`nn.Linear`的两步相同。

看一个与练习参数不同的例子：

```python
import torch
from torch import nn

# 两个输入通道，四个输出通道；每次看三个相邻位置。
# Two input channels, four output channels, and a three-position kernel.
layer = nn.Conv1d(in_channels=2, out_channels=4, kernel_size=3)
inputs = torch.tensor([[[1., 2., 3., 4., 5.], [5., 4., 3., 2., 1.]]])
outputs = layer(inputs)
print(outputs.shape)  # torch.Size([1, 4, 3])
```

主要参数都是整数：

- `in_channels`：输入有几个特征通道，必须匹配输入shape的第1轴。
- `out_channels`：希望学习几条响应序列，由我们选，不必等于输入通道数。
- `kernel_size`：一次看几个相邻时间位置。
- `stride`：每次移动几个位置，默认1。
- `padding`：在时间序列左右各补几个位置，默认0，默认补零。

默认还会学习偏置。返回的预测中间结果是Tensor，排列仍为`(batch, output_channels, output_time)`。

### 为什么长度有时变短？

五个数中，完整的三元素窗口只能放三次，因此上例时间长度由5变3。对本课的`stride=1`和默认膨胀率：

$$
T_{out}=T_{in}+2p-k+1
$$

$T_{in}$是输入长度，$p$是每边补的长度，$k$是核宽。比如8个时刻、核宽3、不补零，输出长度为$8+0-3+1=6$；左右各补1个零，则为$8+2-3+1=8$。

所以本课用`kernel_size=3, padding=1`保持长度8。补的零是边界处理，不是新增的真实行情，也不是缺失值处理的通用答案。

`layer.weight`仍是模型参数属性。本课普通卷积的权重shape为`(输出通道数, 输入通道数, 核宽)`。例如上例为`(4, 2, 3)`，共有24个权重，外加4个偏置；不是每滑一次就多出24个权重。

回到比赛：一个窗口可能共同查看近期几个时刻的价格、价差和成交活动。窗口看几个“时刻”不自动等于固定几“秒”；必须先明确数据时间间隔。

## 6. 怎样让一段序列只输出一个收益预测？

卷积后每个样本仍有很多位置，我们最终却只需要一个数。下面两层作为固定连接代码提供，不要求你机械重写，但需要知道它们做了什么。

### `nn.AdaptiveAvgPool1d(1)`：每条响应序列取一个平均值

这是`torch.nn`的层，参数`output_size=1`表示把时间轴缩成1个位置，而不是只保留1个通道。

输入Tensor `(B, C, T)`，返回Tensor `(B, C, 1)`。例如两个通道分别是`[1, 3, 5]`和`[2, 4, 6]`，池化后分别为`[3]`和`[4]`。

```python
# 对每个通道沿时间求平均，不混合不同样本或不同通道。
# Average over time separately for every sample and channel.
values = torch.tensor([[[1., 3., 5.], [2., 4., 6.]]])
pool = nn.AdaptiveAvgPool1d(1)
pooled = pool(values)
print(pooled)  # tensor([[[3.], [4.]]])
```

“怎么又平均了？”这次先卷积和ReLU，再平均学习到的局部响应，不是直接平均原始价格。但是它仍会丢失精确发生位置，不能据此声称模型完整保留了全局顺序。

注意：它也不会自动忽略人为补齐的缺失时间步。真实数据的缺失、mask和池化选择将在下一课明确，不能把本例的简单平均直接当成全部方案。

### `nn.Flatten(start_dim=1)`：保留样本轴，合并后面的轴

同样来自`torch.nn`。`start_dim`是开始合并的轴编号，默认后面一直合并到最后一轴。输入输出都是Tensor，没有可训练参数。

```python
# 保留第0轴的样本边界，把每个样本剩下的轴合并。
# Keep the batch axis and flatten the remaining axes within each sample.
flatten = nn.Flatten(start_dim=1)
flattened = flatten(pooled)
print(flattened)  # tensor([[3., 4.]])
```

刚才`pooled`为`(1, 2, 1)`，这里变成`(1, 2)`。本课完整模型中，它把`(2, 8, 1)`变成`(2, 8)`，方便交给已学过的`Linear(8, 1)`。

不要用`start_dim=0`把不同样本合并。这里合并轴不是第4节的交换轴，两者不能互相代替。

本课模型的完整shape路线：

```text
(2, 8, 3) 原始教学数据：样本、时间、特征
    ↓ 换轴
(2, 3, 8)
    ↓ Conv1d：3输入通道 → 8输出通道，核宽3，每边补1
(2, 8, 8)
    ↓ ReLU（shape不变）→ 平均池化
(2, 8, 1)
    ↓ Flatten（保留样本轴）
(2, 8)
    ↓ Linear(8, 1)
(2, 1) 每个样本一个预测
```
