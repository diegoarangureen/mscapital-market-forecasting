## 1. 我们遇到了什么麻烦？

普通表格分类中，我们曾经随机抽取 20% 作为验证集。随机切分假设每一行彼此独立，而且训练集与未来实际数据来自相近分布。

金融数据有明确的时间方向。假设真实使用场景是站在第 60 个月预测以后，那么第 61～70 个月的信息在训练时根本还没有发生。

如果随机切分，可能得到：

```text
训练集月份：0, 1, 2, ..., 69, 70
验证集月份：0, 1, 2, ..., 69, 70
```

模型会学习到验证时期附近甚至更晚时期的市场规律，本地分数就可能比真实上线效果更乐观。这是一种时间泄漏（temporal leakage）。

本课采用第一个固定切分：

```text
训练集：month 0～59
验证集：month 60～70
测试集：month 71～108（Kaggle 隐藏答案）
```

这不是最终唯一的切法，但它满足最基本的时间顺序。

## 2. 比较运算会产生布尔值

一个普通数字比较：

```python
result = 3 <= 5
print(result)  # True
```

`<=` 表示“小于或等于”，返回一个 `bool`：`True` 或 `False`。

当 pandas 的一整列参与比较时，比较会对每一行执行一次：

```python
months = data["month"]
train_mask = months <= 59
```

这里：

- `months` 是 `pd.Series`，形状为 `(样本数,)`。
- `train_mask` 也是 `pd.Series`，形状相同。
- `train_mask` 的每个元素都是 `True` 或 `False`。

例如：

```text
month       0      58      60      70
<= 59    True    True   False   False
```

这种由真假值组成、用于决定保留哪些行的对象叫布尔掩码（boolean mask）。

常见错误：不要给整个条件加引号。`"data['month'] <= 59"` 只是普通字符串，不会进行比较。

## 3. `.loc[]`：按照条件选择行

### 它解决什么问题

`.loc[]` 是 pandas DataFrame 的标签索引器（label-based indexer），可以根据布尔掩码保留值为 `True` 的行。

### 来源与是否导入

它属于 pandas DataFrame，不需要额外导入函数；只需已有：

```python
import pandas as pd
```

### 基本语法

```python
selected_data = data.loc[row_mask]
```

注意 `.loc` 后面使用方括号 `[]`，不是圆括号 `()`。它不是一个普通方法调用。

### 输入和返回值

- `data`：一个 DataFrame，形状为 `(全部行数, 列数)`。
- `row_mask`：与 DataFrame 行数相同的布尔 Series。
- 返回：只保留 `True` 所对应行的新 DataFrame，列数通常不变。

### 最小例子

```python
student_data = pd.DataFrame(
    {
        "name": ["A", "B", "C"],
        "score": [60, 85, 90],
    }
)

passed_mask = student_data["score"] >= 80
passed_data = student_data.loc[passed_mask]
print(passed_data)
```

`passed_mask` 是 `[False, True, True]`，所以结果只保留 B 和 C。

### 在当前比赛中的作用

我们用月份条件分别挑出较早的训练行和较晚的验证行。

### 常见错误

掩码长度必须与 DataFrame 行数一致。不能拿另一张行数不同的表所产生的掩码直接筛选当前表。

## 4. `.copy()`：建立独立副本

### 它解决什么问题

筛选后的对象有时仍可能与原 DataFrame 共享部分内部数据。后续给它增加列或修改值时，pandas 可能发出警告，也容易让人不清楚是否会影响原数据。

使用：

```python
selected_data = data.loc[row_mask].copy()
```

可以明确建立一份独立 DataFrame。

### 来源、输入与返回值

- `.copy()` 是 pandas 对象的方法，不需要额外导入。
- 此处不传参数。
- 返回一个独立的 DataFrame，形状与筛选结果相同。

### 最小例子

```python
passed_data = student_data.loc[passed_mask].copy()
```

### 当前作用与注意事项

我们之后会给训练集和验证集添加预测列。现在先 `.copy()`，可以避免无意修改原始 `data`。代价是占用额外内存；标签表约 10 MB，在这里可以接受。将来处理 4.4 GB 的 market 表时不能不加判断地复制整表。

## 5. 分步写法

这一课优先使用容易检查的分步写法：

```text
取出 month 列
→ 分别比较训练边界和验证边界
→ 得到两个布尔掩码
→ 用 .loc[] 选择行
→ 用 .copy() 建立独立数据
→ 打印月份范围检查
```

不要先追求把所有操作压缩成一行。时间边界写错一次，就可能让后面所有模型分数失去意义。
