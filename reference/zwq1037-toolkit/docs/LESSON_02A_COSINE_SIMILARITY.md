## 配套阅读

本课以讲义和数字实验为主，不要求阅读 ISLP 或 D2L。余弦相似度在这里是评价指标，不是 Transformer 中的位置编码余弦函数。

## 1. 从箭头开始理解

二维向量可以想成从原点出发的一支箭头：

```text
[1, 2]
```

表示横向走 1、纵向走 2。

如果预测是：

```text
[2, 4]
```

它是同一方向、长度变成两倍的箭头。余弦相似度只比较方向，因此二者得分为 1。

比赛中不是二维，而是：

```text
真实向量 = [第1个样本的target, 第2个样本的target, ...]
预测向量 = [第1个样本的预测, 第2个样本的预测, ...]
```

标签表有约 125.8 万行，所以它们可以看作两个约 125.8 万维的向量。

## 2. 公式

真实向量记作 $y$，预测向量记作 $p$：

所有 Markdown 阅读器都能显示的版本：

```text
cosine(y, p) = (y · p) / (‖y‖₂ × ‖p‖₂)
```

其中：

```text
y · p   = 点积：对应位置相乘，再全部相加
‖y‖₂    = y 的长度
‖p‖₂    = p 的长度
×       = 两个长度相乘
```

支持 LaTeX 数学渲染的版本：

$$
\operatorname{cosine}(y,p)
=
\frac{y\cdot p}{\lVert y\rVert_2\lVert p\rVert_2}
$$

人话翻译：

```text
分子：两支箭头在多大程度上朝向相同方向
分母：把两支箭头各自的长度影响除掉
```

### 点积

对于：

$$
y=[1,2],\quad p=[2,4]
$$

点积是对应位置相乘再相加：

$$
y\cdot p=1\times2+2\times4=10
$$

纯文本版本：

```text
y · p = 1×2 + 2×4 = 10
```

### 向量长度

$$
\lVert y\rVert_2=\sqrt{1^2+2^2}=\sqrt5
$$

$$
\lVert p\rVert_2=\sqrt{2^2+4^2}=\sqrt{20}=2\sqrt5
$$

纯文本版本：

```text
‖y‖₂ = √(1² + 2²) = √5
‖p‖₂ = √(2² + 4²) = √20 = 2√5
```

所以：

$$
\frac{10}{\sqrt5\times2\sqrt5}=1
$$

纯文本版本：

```text
10 / (√5 × 2√5) = 1
```

## 3. 三个重要结果

### 同方向：1

```text
真实：[1, 2]
预测：[2, 4]
```

虽然数值放大了两倍，但方向完全相同，得分为 1。

### 方向不完全一致：介于 -1 和 1

```text
真实：[1, 2]
预测：[2, 1]
```

点积为 4，两边长度都是 $\sqrt5$：

$$
score=\frac{4}{5}=0.8
$$

### 完全反向：-1

```text
真实：[1, 2]
预测：[-1, -2]
```

预测方向完全相反，得分为 -1。

分数越接近 1 越好；0 表示整体上没有对齐；负数表示方向总体相反。

## 4. 为什么全零预测有问题？

零向量：

```text
[0, 0]
```

长度是：

$$
\sqrt{0^2+0^2}=0
$$

余弦公式的分母会出现：

$$
\lVert y\rVert_2\times0=0
$$

除以 0 在数学上没有定义。具体评分程序可能返回 0、`NaN` 或拒绝计算，但全零预测不会成为有效方案。

## 5. 为什么缩放预测不改变得分？

如果把所有预测乘以正数 10：

$$
p' = 10p
$$

点积会放大 10 倍，预测长度也会放大 10 倍，两者抵消。因此：

$$
\operatorname{cosine}(y,10p)=\operatorname{cosine}(y,p)
$$

这不表示预测幅度永远没有意义，而是 Kaggle 这个指标不惩罚统一的正比例缩放。不同样本之间的相对大小和正负方向仍然重要。

## 6. 和 ROC-AUC 的区别

上一场是二分类：ROC-AUC 主要关心正样本是否排在负样本前面。

本场是连续回归：余弦相似度关心整列预测与整列真实目标的方向是否对齐，正负号和相对幅度都会影响分数。

```text
ROC-AUC：分类排序
Cosine Similarity：连续向量方向
```

## 7. 三个 NumPy 工具

### `np.array()`

- 来源：NumPy，需要 `import numpy as np`。
- 作用：把 Python 列表变成数值数组。
- 语法：`np.array([数值...], dtype=float)`。
- 返回：`numpy.ndarray`，本课形状是 `(2,)`。
- 注意：Python 从 0 开始索引；`(2,)` 表示含两个元素的一维数组。

### `np.dot()`

- 作用：本课用来计算两个一维数组的点积。
- 语法：`np.dot(first_array, second_array)`。
- 输入：长度相同的两个一维数组。
- 返回：一个数值标量。
- 注意：长度不一致会报形状不匹配错误。

最小例子：

```python
first = np.array([1.0, 2.0])
second = np.array([3.0, 4.0])
result = np.dot(first, second)  # 1*3 + 2*4 = 11
```

### `np.linalg.norm()`

- 作用：计算向量的欧几里得长度（L2 norm）。
- 语法：`np.linalg.norm(array)`。
- 输入：数值数组。
- 返回：非负浮点数。
- 注意：全零数组的长度是 0。

最小例子：

```python
vector = np.array([3.0, 4.0])
length = np.linalg.norm(vector)  # 5.0
```
