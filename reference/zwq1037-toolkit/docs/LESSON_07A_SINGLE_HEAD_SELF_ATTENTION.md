# 第7A课：让每个时间步主动寻找相关时刻

## 1. 本课目标

CNN用固定宽度的卷积核检查局部窗口。若第20个位置的信息与第180个位置有关，信息必须经过多层卷积才能逐渐传过去。自注意力（self-attention）换了一个问题：**对当前时间步而言，整段序列中的哪些时间步最值得参考？**

本课只掌握两件事：

1. 把数值时间序列表示成Transformer习惯的`(batch, time, features)`。
2. 手工完成一次单头缩放点积自注意力（single-head scaled dot-product self-attention）。

本课不训练模型，不引入多头注意力、位置编码、padding mask或完整`TransformerEncoder`。这些内容会在后续课程逐项加入。

## 3. 从CNN的shape切换到Transformer的shape

我们的正式序列缓存中，一个batch的原始排列是：

```text
(B, 14, 200) = (样本数, 通道数, 时间步数)
```

前13个通道是市场特征，第14个通道是有效位置mask。CNN要求特征通道在中间，所以直接使用这种排列。Transformer通常把每个时间步当成一个token，因此市场特征部分会换轴为：

```text
(B, 13, 200) → (B, 200, 13)
                 样本  时间  特征
```

后面不会把padding mask混在13个市场数值里：它会单独传给注意力层，告诉模型哪些位置只是补齐。第7A的玩具序列没有padding，所以先不写mask。

注意，这只是**一个样本内部**的200个位置相互建立关系。普通Transformer也不会自动记住前一个batch，更不会把不同样本或不同月份连接成一条隐藏状态。它解决的是“当前样本内部的远距离交互”，不是“连续batch记忆”。

## 4. Query、Key、Value到底在做什么？

把每个时间步想成一条市场记录：

- 查询（query，Q）：当前时间步在问“我现在需要参考什么信息？”
- 键（key，K）：每个候选时间步提供“我包含什么模式”的索引。
- 值（value，V）：一旦某个位置被选中，真正汇总进结果的信息。

查询与某个键越匹配，这个键对应的值就获得越大的权重。正式Transformer会用三个可学习的线性层分别生成Q、K、V；为了先隔离核心计算，本课令`Q = K = V = X`。

“self”表示Q、K、V来自同一段输入序列，不表示每个位置只看自己。相反，每个查询都可以查看这段样本内的全部位置。

## 5. 一个三时间步的完整数字例子

这里只有1个样本、3个时间步、每步2个特征：

```text
X = [
      [1, 0],
      [0, 1],
      [1, 1]
    ]

shape = (1, 3, 2)
```

令`Q = K = V = X`。先用每个查询和每个键做点积，得到相似度分数：

$$
S=\frac{QK^\top}{\sqrt{d}}
$$

$d=2$是每个查询和键的特征维度。未缩放的$QK^\top$为：

```text
[[1, 0, 1],
 [0, 1, 1],
 [1, 1, 2]]
```

例如第一行来自查询`[1, 0]`：它与三个键的点积依次为1、0、1。除以$\sqrt{2}\approx1.414$后再对每一行做softmax：

```text
注意力权重约为
[[0.4011, 0.1978, 0.4011],
 [0.1978, 0.4011, 0.4011],
 [0.2483, 0.2483, 0.5035]]
```

每一行都是一个查询对三个候选位置的分配，行和为1。最后用这些权重加权对应的值：

$$
Y=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V
$$

得到：

```text
Y约为
[[0.8022, 0.5989],
 [0.5989, 0.8022],
 [0.7517, 0.7517]]
```

输出仍有3个时间步、每步2个特征，所以shape仍是`(1, 3, 2)`；但每个输出位置现在混合了整段序列的信息。

为什么除以$\sqrt d$？当$d$变大时，点积的绝对值通常也会变大，softmax容易过早变得接近“只选一个位置”。缩放让分数幅度更稳定。比如$d=2$时除以约1.414；它不会改变shape。

一个关键边界：上面的计算没有给出“第0步比第2步早”的信息。若交换时间步，自注意力会跟着交换结果，却不天然理解先后。之后必须加入位置编码。

## 6. 三个本课接口

### `Tensor.transpose(dim0, dim1)`：交换两个轴

1. 解决的问题：让键从`(B, T, F)`变成`(B, F, T)`，以便计算每个查询与每个键的点积。
2. 来源：PyTorch Tensor的方法；已有`import torch`，无需额外导入。
3. 基本语法：`new_tensor = old_tensor.transpose(dim0, dim1)`。
4. 输入：一个Tensor和两个整数轴编号；本课输入`(B,T,F)`，交换轴1与2。
5. 返回：共享原数据存储的Tensor视图，shape为`(B,F,T)`。
6. 最小例子：`torch.ones((2, 3, 4)).transpose(1, 2)`得到shape`(2, 4, 3)`。
7. 项目作用：为`QK^T`准备键矩阵。
8. 常见错误：写成`transpose(0, 1)`会交换样本轴和时间轴，把不同样本的边界弄乱。

它与已学过的`permute(0, 2, 1)`不同：`transpose`一次只交换两个轴，`permute`可以一次指定全部轴的新顺序。

### `torch.bmm(input, mat2)`：逐样本做矩阵乘法

1. 解决的问题：一个batch中的每个样本都要独立做矩阵乘法。
2. 来源：PyTorch函数；需要`import torch`。
3. 基本语法：`result = torch.bmm(first, second)`。
4. 输入：两个三维Tensor；shape分别为`(B,N,D)`和`(B,D,M)`，batch大小及中间维度必须匹配。
5. 返回：三维Tensor，shape为`(B,N,M)`。
6. 最小例子：`torch.bmm(torch.ones((2,3,4)), torch.ones((2,4,5)))`返回shape`(2,3,5)`。
7. 项目作用：第一次计算`QK^T`得到`(B,T,T)`分数；第二次计算权重乘V得到`(B,T,F)`上下文。
8. 常见错误：用`*`代替；`*`是逐元素乘法，不是这里需要的矩阵乘法。

本课第一次`bmm`的shape路线是：

```text
(B,T,F) × (B,F,T) → (B,T,T)
```

第二次是：

```text
(B,T,T) × (B,T,F) → (B,T,F)
```

### `torch.softmax(input, dim)`：把一组分数变成权重

1. 解决的问题：把任意实数分数转成0到1之间、总和为1的权重。
2. 来源：PyTorch函数；需要`import torch`。
3. 基本语法：`weights = torch.softmax(scores, dim=轴编号)`。
4. 输入：Tensor，以及沿哪个轴归一化的整数`dim`。
5. 返回：与输入shape相同的Tensor。
6. 最小例子：`torch.softmax(torch.tensor([0.0, 0.0]), dim=0)`得到`[0.5, 0.5]`。
7. 项目作用：对每个查询，在全部候选键之间分配注意力；本课分数为`(B,T,T)`，所以用`dim=-1`沿最后一个轴处理。
8. 常见错误：写成`dim=1`会跨查询位置归一化，回答的就不是“这个查询应怎样分配给所有键”。

`dim=-1`表示最后一个轴。Python轴编号从0开始；对`(B,T,T)`而言，最后一个轴就是被参考的键位置。
