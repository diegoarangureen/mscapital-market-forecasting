# 外部教材配套方案

项目实战负责“真实问题、实验习惯和迁移能力”，教材负责“补齐理论和知识结构”。采用按需阅读（just-in-time reading）：不暂停项目通读教材，而是在每一课开始时指定本课真正相关的章节。

## Python：遇到再学

不单独安排 Python 基础课程。出现新的语法、函数、类或对象时，由 Codex 在当前任务中解释用途、调用方式、输入输出和最小例子。

Python 及常用库的官方 API 文档主要由 Codex 查阅、核对版本并转化为适合当前程度的讲解，不作为学习者的常规课外阅读。讲解仍须覆盖来源、导入、基本语法、输入、返回值、最小例子、比赛用途和常见错误。

只有当“独立查找接口”本身成为某节课明确要训练的能力时，才安排学习者亲自查看文档；必须提前说明查什么、为什么值得亲手查以及看到哪里停止，不能用一句“去看官方文档”代替教学。

[CS50P](https://cs50.harvard.edu/python/) 只保留为可选参考，不列入项目必修进度。

## 与机器学习项目同步：ISLP

教材：[An Introduction to Statistical Learning（Python 版）](https://www.statlearning.com/)

用途：补齐监督学习、过拟合、验证、线性模型、树模型和神经网络背后的逻辑。它比纯数学教材更适合当前阶段，而且官方提供 Python 版免费下载。

使用方法：由每课讲义指定章节和小节，不按顺序硬啃全书。

树模型部分的使用边界：学习者已在上一项目完成决策树、随机森林、Gradient Boosting、LightGBM 和 early stopping。除非间隔较久后复习检查显示遗忘，或本项目出现更深入的新问题，否则不再安排树模型入门章节。ISLP 在阶段 4 只用于补充尚未掌握的理论，不重复已经能够解释和运行的内容。

## 进入 PyTorch 后：《动手学深度学习》

教材：[《动手学深度学习》第二版](https://zh.d2l.ai/)

用途：把公式、图和 PyTorch 代码连起来，覆盖多层感知机、CNN、注意力与 Transformer。

使用方法：项目进入 PyTorch、MLP、CNN 和 Transformer 阶段时，由对应课程指定章节；不需要先通读全书。

## 量化方向的后期选读

教材：[Machine Learning for Algorithmic Trading](https://www.ml4trading.io/second-edition/)

用途：建立从金融数据、因子、机器学习验证到回测和交易策略的全流程认识。

使用方法：暂时不作为主教材。完成时间验证和第一个基线后再按课选读。书中的代码环境可能与当前版本不同，重点学习方法，不直接复制整套环境。

## 中文量化概念参考：Quant Wiki

网站：[Quant Wiki 中文量化百科](https://quant-wiki.com/)

用途：用中文快速建立金融术语和量化概念的直觉，例如收益率、波动率、夏普比率、回测、限价单、相关性和市场中性。

定位：补充参考，不作为唯一主教材。网站内容以百科、科普和社区文章为主，部分结论为了入门会简化；涉及公式假设、实证数字、策略有效性和投资建议时，需要再用教材、论文或官方资料核对。

使用方法：每课只指定与当前问题直接相关的页面。优先阅读网站自有的概念文章；不从来源或授权不明确的“图书馆/资源包”下载材料。

特别注意：

- 日收益夏普率乘 `sqrt(252)` 隐含收益过程足够稳定、频率一致等假设；存在自相关时不能机械使用。
- 标准差只描述波动，不等于全部风险，无法完整反映尾部亏损、流动性和回撤。
- 无摩擦模型中杠杆可能不改变夏普率；真实交易中的融资成本、手续费、滑点、强平和容量会改变结果。
- 本次 Kaggle 的余弦相似度是预测指标，不是策略夏普率。预测得分高不自动代表可以赚钱。

## 每课如何安排阅读

每份新讲义增加“配套阅读”小节，并明确：

- 书名、版本、章/节标题；
- 课前读还是课后读；
- 精读、理解直觉还是仅浏览；
- 哪些公式或代码可以暂时跳过；
- 读完需要回答的 1～3 个问题。

如果不同版本的章节编号不一致，将同时写出章节标题，以标题为准。

## 已完成阅读记录

新课选择资料前先检查这里。已经读过的页面默认作为前置知识，短期内不机械重复布置。出现以下情况时可以安排间隔复习：

- 距离首次学习已经较久，而本课马上需要这个概念；
- 课前检查问题表明关键概念已经遗忘或混淆；
- 同一资料中还有本课需要的更深层内容。

重复时必须标成“复习”而不是“新阅读”，并写清本次复习目标。通常先用 1～2 个小问题检查记忆：能回答就只看摘要，不能回答再重读对应小节，不要求无差别重读整页。
