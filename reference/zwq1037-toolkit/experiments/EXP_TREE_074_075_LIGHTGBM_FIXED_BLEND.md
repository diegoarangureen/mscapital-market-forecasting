# EXP-TREE-074/075：LightGBM800 固定小权重融合

## 实验设置

补齐训练 0–49、验证 50–59 的固定 LightGBM800 预测。模型严格沿用 EXP067：307 特征、31 叶、学习率 0.03、最小叶样本 100、L2=1、列采样 0.8、seed 42 和两个 CPU 线程。50–59 单模 cosine 为 0.138521。

完整候选不搜索权重，只从 Public 0.135 配方中的旧 XGBoost 划出 4.5% 最终权重：

- 67.5% Relative319 TabM trim1
- 13.5% 旧 XGB053R
- 4.5% LightGBM800
- 4.5% 双种子 GRU 嵌入树
- 10% 双种子 Joint-GRU

比较基准使用相同验证预测严格复现的 Public 0.135 本地配方，其余组件与归一化方式保持不变。

## 结果

| 验证指标 | 候选相对当前配方 |
|---|---:|
| 50–59 overall | **-0.000121** |
| 60–70 overall | +0.000143 |
| 60–70 去除 66 | +0.000047 |
| 62–70 去除 66 | +0.000052 |
| 67–70 | +0.000048 |

预设门槛是50–59至少提高0.0001、62–70去除66至少提高0.0001。候选在开发窗下降，确认窗重点切片也未达到门槛，因此不晋级。

## 结论

LightGBM800 的预测差异没有在固定4.5%权重下转化为稳定的完整融合收益。停止该方向，不继续搜索LightGBM权重、树数或叶子数。下一步回到延长Joint-Transformer训练的主实验。
