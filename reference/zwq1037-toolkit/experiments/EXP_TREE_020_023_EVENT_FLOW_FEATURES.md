# EXP-TREE-020 至 EXP-TREE-023：主动成交、委托事件与盘口深度交叉

## 固定口径

- 训练月份：0--59；正式验证月份：60--70。
- 内部前向验证：训练0--49，验证50--59。
- 官方指标：未中心化 whole-vector cosine。
- 基线：EXP-TREE-016，132个可从 market 复现的特征，XGBoost深度5、400棵树、target减训练期均值。
- 每组事件特征均从同一132特征基线开始；只有两组分别通过后才测试合并。
- 未做smoke test；直接聚合完整的103,970,264行transaction和170,056,583行order。

## 新增特征

### 主动成交8列

- 最近60秒、20秒主动买卖成交量不平衡。
- 最近60秒主动买卖成交笔数不平衡。
- 买卖双方平均单笔成交量不平衡。
- 最近20秒相对前40秒的成交压力变化。
- 总成交量和总成交笔数的`log1p`。
- 最近一笔成交距离预测时点的秒数。

### 新增/撤单8列

- 新增买卖单量不平衡。
- 撤卖减撤买形成的撤单方向压力。
- 新增买减新增卖减撤买加撤卖形成的净委托压力。
- 买方、卖方及全体撤单比例。
- 最近20秒净委托压力及其相对前40秒的变化。

### 成交压力与可见深度交叉5列

- 主动买量相对卖一平均深度的`log1p`强度。
- 主动卖量相对买一平均深度的`log1p`强度。
- 两侧消耗强度之差。
- 主动成交不平衡减去盘口不平衡。
- 主动成交不平衡乘以盘口不平衡。

## 数据质量审计

- 两张特征表均为1,257,637行，sample_id唯一且完整。
- 所有方向不平衡均处于理论范围；两窗口压力差处于[-2, 2]。
- 无无穷值。最近20秒没有对应事件时保留缺失，由XGBoost缺失分支处理。
- 成交和委托量聚合使用64位整数，避免大样本求和溢出。
- train与test事件表字段一致，公式不依赖month或target，可以在测试集复现。

## 稳定性解释

- EXP-TREE-020的正式最差月份为70月，cosine为0.11391；所有月份仍为正。
- EXP-TREE-023相对132基线在11/11个月都提高，最差月份为70月，cosine为0.11107。
- 但EXP-TREE-023相对EXP-TREE-020只在5/11个月提高，额外总分主要受66月从0.18022提高到0.18844推动。
- 剔除60、61月后，EXP-TREE-023仍为最高分0.13998，EXP-TREE-020为0.13780，模型排序不变；新特征增益并非依赖最前面两个月。
- 因此EXP-TREE-023是当前最高分可复现模型；EXP-TREE-020月度标准差更低、最差月更高，是更稳健的并行候选。
- 新增/撤单组单独有效，但与主动成交直接合并未超过主动成交单组，说明订单事件包含互补信息，同时也可能稀释主要信号。

## 特征重要度观察

在EXP-TREE-023中，事件类特征的gain重要度以`trade_volume_imbalance_20`最高，明显高于其他事件列。随后是60秒成交笔数不平衡、60秒成交量不平衡、最后成交新鲜度和总成交量。这支持下一轮优先细化10/20/40秒主动成交压力，而不是一次增加更多宽泛统计量。

## 结论

主动成交方向是这轮最强的新信息源，并在内部折和正式验证中一致提升。成交压力与盘口深度交叉进一步提高总体分数，但增加了月份间波动。后续若优化，应先围绕EXP-TREE-020做多随机种子稳定性检查，或对20秒主动成交组做小规模窗口消融；不要继续无约束地合并全部订单特征。

从后续实验开始，不再为每个候选额外训练0--49/50--59内部模型。统一报告正式60--70 whole-vector cosine、鲁棒性62--70 whole-vector cosine、逐月均值/标准差、最差月和改善月份数。这样减少约一半训练成本；代价是更容易反复迎合固定验证期，因此62--70只能作为子区间敏感性检查，不能被解释为新的独立留出集。
