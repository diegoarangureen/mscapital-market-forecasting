# EXP-CNN-001：Market序列mask-aware 1D CNN

## 实验问题

第一版market序列CNN在相同forward validation上，能否从逐时刻序列中学到超过聚合MLP、并接近或超过LightGBM的方向信号？

## 实验设置

- 日期：2026-09-09
- 输入：每个样本最多200个market记录，14通道，短样本左padding并右对齐
- 模型：两层`Conv1d(14→32→32)`，两层核宽均为5，ReLU，mask-aware mean pooling，单输出Linear
- 损失：MSE
- 优化器：Adam，学习率0.001
- batch size：512
- epoch数：10
- 训练批次：每轮2,079个连续块，块级随机排列
- 训练月份：0～59
- 验证月份：60～70
- 训练样本数：1,064,163
- 验证样本数：193,474
- 选择标准：每轮完整验证集cosine，保存最高分权重

## 正式结果

- 最佳epoch：10
- 最佳forward-validation cosine：0.0617277457
- 恢复权重后cosine：0.0617277457
- MLP基线：0.0446837080
- 相对MLP：+0.0170440377
- LightGBM EXP-002：0.1038700392
- 相对LightGBM：-0.0421422935
- 第10轮耗时：69.08秒
- Kaggle分数：尚未提交

逐轮验证cosine：

```text
0.029169, 0.041332, 0.021814, 0.024737, -0.008597,
-0.000799, 0.033167, 0.011361, 0.054655, 0.061728
```

验证分数明显波动，最佳轮恰好是最后一轮。它说明当前10轮范围内没有观察到明确的验证峰值回落，但不能单凭最后一轮最高就断言继续训练一定提高。

## 最佳预测诊断

- 预测行数：193,474，全部有限
- target均值/标准差：0.00003971 / 0.00292967
- prediction均值/标准差：0.00017427 / 0.00016288
- prediction范围：-0.00428411 ～ 0.02151993
- 模型验证MSE：0.00000855519
- 全零预测MSE：0.00000858457
- Pearson相关：0.0759070

CNN输出波动远小于真实标签，且MSE只略好于全零预测；但它学习到一定方向信号，因此cosine超过聚合MLP。该证据也表明训练MSE不能替代验证cosine。

## 按月稳定性诊断

完整验证分数会掩盖月份间差异。将同一份最佳预测按验证月份拆开后得到：

| month | 样本数 | cosine |
|---:|---:|---:|
| 60 | 17,770 | -0.024215 |
| 61 | 17,711 | 0.024287 |
| 62 | 17,739 | 0.060630 |
| 63 | 17,744 | -0.018039 |
| 64 | 17,740 | 0.060630 |
| 65 | 17,691 | 0.014475 |
| 66 | 17,187 | 0.116373 |
| 67 | 17,515 | 0.069463 |
| 68 | 17,326 | 0.049817 |
| 69 | 17,454 | -0.039149 |
| 70 | 17,597 | 0.123683 |

模型在month 60、63和69出现负相关，而在66和70明显较高，说明`0.061728`不是每个月都稳定取得的能力。month 66的target与prediction波动也明显高于多数月份，对整体余弦可能具有较大影响；整体余弦不是各月余弦的简单平均。

当前CNN只沿单个样本内部200个记录位置做卷积。month只用于划分训练和验证，没有作为输入，也没有把不同sample连接成跨月序列。block shuffle改变样本批次顺序，但即使按month顺序喂给普通前馈CNN，模型也不会自动保留上一batch的状态。因此下一步应优先做按月稳定性/时间漂移审计，再决定是否加入可安全外推的时间或状态信息。

## 结论边界

- 结果支持第一版逐时刻CNN学到了聚合MLP未充分利用的信号。
- CNN仍明显落后于使用62个人工聚合特征的LightGBM。
- 差异来自整套输入表示和模型流程，不能解释为纯粹的模型类型因果比较。
- 当前结果不足以判定CNN不适合本任务，也不足以判定只增加epoch就一定提高。
- 当前整体验证分数掩盖明显的跨月波动，不能只用单个汇总值判断部署到未来月份的稳定性。
- 下一实验应一次只改变一个主要因素，并继续保存最佳验证轮。
