# Kaggle Relative319 TabM + 同月 40 列特征实验

日期：2026-09-13。Notebook：`zwq1037/relative319-xs-tabm-notebook` v1，状态 COMPLETE。原生 Notebook 成功获得 GPU 并训练；旧 script Notebook 的 GPU 启动问题与缺少特征文件无关。

对照组：319 原特征；候选：同一 319 特征另加选定 20 列的同月 percentile rank 和同月 z-score，共 40 列。两组同 seed42、15 epoch、相同训练与验证切分。仅比较同一次 Kaggle 运行的候选减对照，避免把环境差异当作特征收益。

| 60–70 | 0.176628 | 0.176416 | -0.000212 |
| 62–70，两个月间隔 | 0.178852 | 0.178693 | -0.000159 |
| 62–70，去掉 66 月 | 0.153752 | 0.156241 | +0.002489 |
| 67–70 | 0.153183 | 0.155625 | +0.002442 |

66 月单月 cosine 从 0.234868 降到 0.225893，差值 -0.008975；70 月从 0.125807 升到 0.140237，差值 +0.014429。候选月度标准差下降 0.003247，最差月提升 0.007834；但整体 62–70 仍略低，且 rank 与 z-score 同时加入，不能确定哪一类特征有贡献。

结论：有值得追踪的近期增益，但未通过完整的两个月间隔窗口，暂不替换主力模型或提交 Kaggle。正式测试数据目前没有可直接复用的 month 字段，同月变换的部署方式也尚未解决。
