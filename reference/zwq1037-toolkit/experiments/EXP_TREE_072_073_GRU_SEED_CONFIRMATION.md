# EXP-TREE-072/073：GRU 嵌入树第二种子与种子集成

## 固定确认

EXP-TREE-072 只把 GRU 编码器从 seed 42 换为 seed 137；XGBoost 保持 seed 42，模型参数和外层划分不变。预先固定的配方为：树篮子内 75% Relative319 TabM、20% 旧 XGB053R、5% GRU 嵌入树，然后树篮子占最终预测 90%，Joint-GRU 占 10%。因此最终有效权重为 67.5%、18%、4.5%、10%。

| 验证窗 | seed 42 | seed 137 |
|---|---:|---:|
| 50–59 | +0.001265 | +0.000721 |
| 60–70 | +0.000379 | +0.000898 |
| 60–70（去除 66） | +0.000779 | +0.000917 |
| 62–70（去除 66） | +0.000689 | +0.000818 |
| 67–70 | +0.000981 | +0.001331 |

两个独立种子在所有重点窗口均优于当前 B001，固定的小权重用法得到确认。

## 双种子平均

EXP-TREE-073 对两个 Joint-GRU 预测先做单位化平均，也对两棵嵌入树预测做单位化平均，再使用同一固定配方。

| 验证窗 | 相对当前 B001 的提升 |
|---|---:|
| 50–59 | +0.001077 |
| 60–70 | +0.000787 |
| 60–70（去除 66） | +0.000852 |
| 62–70（去除 66） | +0.000752 |
| 67–70 | +0.001215 |

双种子平均没有取单个种子在某个窗口的最高点，但跨窗口更均衡，因此晋级全量训练。
