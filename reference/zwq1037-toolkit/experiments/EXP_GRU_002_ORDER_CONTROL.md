# EXP-GRU-002：事件顺序与无序汇总对照

日期：2026-09-12

## 目的与预注册门槛

检验市场逐笔事件的先后顺序是否能给当前 319 特征 Quantile TabM 提供稳定的增量信息。

固定门槛：

1. `90% static + 10% GRU` 在 40-49、50-59 两个验证窗口都必须提升。
2. 两折平均提升至少 0.0015。
3. GRU 的平均提升必须超过不使用事件顺序的 masked mean/max 汇总网络。

未通过时不扩展到 60-70 月、不增加第二随机种子，也不生成正式提交。

## 设置

- 序列：完整 200 步市场缓存，不再像旧 EXP-GRU-001 那样隔点降采样为 100 步。
- 输入：14 个缓存通道和 8 个仅由当前样本序列派生的通道。
- GRU：hidden size 64，单层，约 35,137 参数。
- 对照：共享逐事件投影后做 masked mean/max 的 MLP，约 18,497 参数；不保留事件顺序。
- 训练：每折只用训练月份拟合输入标准化和目标标准化，MSE，2 epochs，seed 42。
- 验证：0-39 训练/40-49 验证；0-49 训练/50-59 验证。
- 融合：预测先做 L2 单位化，再固定 `90% relative319 static + 10% sequence model`。
- 资源：GPU 训练，CPU 线程限制为 2。

## 结果

| 验证窗口 | static | GRU | static90+GRU10 | GRU blend delta | summary | static90+summary10 | summary blend delta |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 40-49 | 0.151020 | 0.104759 | 0.150691 | -0.000329 | 0.058457 | 0.149705 | -0.001315 |
| 50-59 | 0.154393 | 0.110902 | 0.154473 | +0.000080 | 0.087234 | 0.154005 | -0.000388 |
| 两折平均 delta | | | | **-0.000125** | | | **-0.000852** |

波动方面，GRU 融合在两个窗口都略微降低月度标准差，并分别把最差月提高约 0.00049 和 0.00101；但主 cosine 没有稳定提升，不能只凭波动改善保留它。

## 结论

预注册门槛未通过：

- GRU 两个窗口并非都提升。
- 平均 delta 为负，离 `+0.0015` 门槛很远。
- GRU 明显强于无序汇总网络，说明事件顺序包含可学习信息；但这部分信息与强静态模型高度重合，或当前直接目标训练没有把互补信息提取出来。

因此停止当前 GRU 路线，不扩展 60-70 月和 seed 137，不做正式训练或 Kaggle 提交。旧 EXP-GRU-001 与本次更公平的完整序列实验都没有带来稳定融合增益，继续微调 GRU 的投入产出比偏低。
