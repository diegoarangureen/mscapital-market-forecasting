# EXP-CNN-003：近期加权CNN训练20轮

## 实验问题

EXP-CNN-001和EXP-CNN-002的最佳验证轮都落在预设的epoch 10边界。保持EXP-CNN-002的数据、网络、月份权重和优化设置不变，只把训练上限从10轮增加到20轮，能否观察到10轮之后的新最佳结果？

## 公平设置

- 输入：同一份(1_257_637,14,200) market序列缓存
- 训练月份：0～59，共1,064,163个样本
- 验证月份：60～70，共193,474个样本
- 模型：两层Conv1d(14→32→32)、kernel size 5、ReLU、masked mean pooling、单输出Linear
- 损失：与EXP-CNN-002相同的线性近期月份加权MSE
- 优化器：Adam，学习率0.001
- batch size：512
- 随机种子：42
- 唯一计划变化：训练上限10→20 epoch

脚本从头训练20轮，没有从EXP-CNN-002最佳权重续训，避免重置Adam状态形成额外变量。

## 验收与解释边界

- 配置、历史、最佳权重、最佳预测和逐月分数均存在；保存后恢复分数一致。
- 独立复算确认预测与原label的sample_id、month和target逐行一致。
- 本次运行中，epoch 13、14、17～20均超过该运行epoch 10，其中epoch 20刷新到0.108993，支持原10轮上限过短。
- EXP-CNN-003和EXP-CNN-002虽使用相同随机种子，但前10轮轨迹并不相同，说明当前CUDA训练没有达到严格逐位确定。因此相对EXP-CNN-002的+0.047235不能全部解释为“额外10轮”的纯因果效应。
- 即使如此，本次单独运行在10轮之后持续产生多个明显更高的验证点，并且11个月全部为正，结果不是由某个负分月份被总体掩盖。
- 最佳轮仍落在epoch 20边界，说明继续训练可能还有空间；但验证曲线波动明显，不应无限增加上限或把单次运行当作稳定结论。
