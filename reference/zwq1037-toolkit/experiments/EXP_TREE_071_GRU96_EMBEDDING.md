# EXP-TREE-071：冻结 Joint-GRU 表征加入 XGBoost

## 目标

检验已经训练好的 Joint-GRU 是否学到了 319 个静态特征之外、能被树模型利用的序列信息。每个外层验证段使用只见过更早月份标签的编码器，导出 96 维序列表征，再与 319 个静态特征拼接训练 XGBoost。

## 固定设置

- GRU 编码器：seed 42、epoch 6，冻结参数。
- 树模型：800 棵树、深度 5、学习率 0.03、`min_child_weight=100`、`colsample_bytree=0.8`。
- 特征：319 个静态特征 + 96 个 GRU 表征，共 415 个。
- 验证：训练 0–49 / 验证 50–59；训练 0–59 / 验证 60–70。
- 外层验证标签没有进入编码器或树模型训练。树训练行的 GRU 表征来自同一训练段内训练的编码器，因此属于训练内监督表征；本实验用于候选筛选，不把它描述为逐行 OOF stacking。

## 结果

在 50–59，纯嵌入树相对 319 特征树提高 `+0.000431`。用嵌入树完全替换原组合中的 25% 旧树后，再加入 10% Joint-GRU，最终相对当前 B001 提高 `+0.001797`；当前 B001 加 10% Joint-GRU为 `+0.001001`。

在 60–70，纯嵌入树整体下降 `-0.003634`，主要由月份 66 驱动；排除 66 后提高 `+0.001449`，62–70 排除 66 提高 `+0.001034`，67–70 提高 `+0.002808`。完整替换 25% 树权重会使最终组合整体下降 `-0.000020`，但在后三个重点时间窗分别提高 `+0.001003`、`+0.000845`、`+0.001530`。

对保存预测做固定线性插值后，嵌入树占总权重 5%、旧树占 20%、TabM 占 75%，再与 10% Joint-GRU 融合，是兼顾两个验证段的稳健点：

| 验证窗 | 相对 B001 的提升 |
|---|---:|
| 50–59 | +0.001265 |
| 60–70 | +0.000379 |
| 60–70（去除 66） | +0.000779 |
| 62–70（去除 66） | +0.000689 |
| 67–70 | +0.000981 |

## 结论

GRU 表征包含可被树模型利用的增量信息，但 25% 全量替换对月份 66 过于敏感。下一步固定 5% 总权重，不再调权重，并只替换为 seed 137 编码器做独立确认。
