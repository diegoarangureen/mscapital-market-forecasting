# EXP-TREE-024～026：公开 Notebook 特征消融

## 实验设置

- 共同基线：EXP-TREE-020，132个盘口特征加8个成交事件流特征。
- 模型固定：XGBoost，深度5，400棵树，其他参数不变。
- 训练月份：0～59；验证月份：60～70。
- 指标：官方未中心化 whole-vector cosine。
- 额外诊断：62～70、62～70去掉异常偏易的66月、逐月标准差和最差月份。

## 结论

EXP-TREE-025胜出。它相对EXP-TREE-020的60～70提升为`+0.00213930`，62～70去掉66月提升为`+0.00280618`；相对旧订单组合EXP-TREE-022提升`+0.00345233`。它不是依靠66月获得提升：66月反而比EXP-TREE-020下降`0.000936`，主要收益来自60、62、64、67、68和69月。

EXP-TREE-024只带来`+0.00081311`总体提升，去掉66月后只剩`+0.00009428`，且月度波动增加，不应直接成为主线。

EXP-TREE-026整体有`+0.00138008`，但月度标准差最高，70月下降`0.009817`。指数衰减有信号，但当前21列整组加入不够稳，后续若继续应只保留贡献明显的短长差特征做精简消融。

## 重要性观察

- 多窗口订单组最重要的新增列是`net_order_pressure_30`和`new_order_volume_imbalance_10`。
- 多窗口成交流最重要的是10秒signed amount、10秒成交笔数不平衡和30秒成交笔数不平衡。
- 指数衰减组最重要的是30秒减120秒的MicroPrice displacement、30秒OFI及其短长差。
