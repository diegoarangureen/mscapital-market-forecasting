# EXP-EVAL-001：多泛化评估面板
日期：2026-09-12

## 评估口径

保留四个独立主分数，不生成加权总分：
1. 50–59 cosine：训练0–49，检验较早的向前迁移。
2. 60–70 去66月 cosine：训练0–59，观察紧邻训练期及后续月份。
3. **62–70 去66月 cosine**：同一0–59训练模型，隔开60、61两个月后评分。这是有意设计的两个月隔离，不是旧口径错误。
4. 67–70 cosine：观察较远的晚期表现。

同时记录60–70 overall、62–70 overall。每个窗口分别输出逐月标准差（ddof=0）、Q25（线性分位数）、最差月及月份、改善月份数量，以及每一次删去一个月后的 pooled cosine 和相对基线 delta。窗口总分直接在样本预测上计算，不等于逐月分数的平均。

62–70是同一份验证预测的时间子集，不额外训练，也不把60、61月用于调参。四个主指标存在重叠，不能当成四次统计独立验证；隔两个月是当前项目的诊断设计，不自动证明任何标签期限下都完全无泄漏。

test-likeness、adversarial AUC不进入准入或Pareto比较。没有改变训练损失。

## 准入与Pareto规则 v1

以下数值是本次为后续实验固定的工程筛选标准，不是统计显著性结论，也不是用户此前指定的精确数值：

- 四个主分数相对固定基线均不得下降（仅容忍1e-12计算误差）。
- 至少一项主分数提升不低于0.001。
- 四个主窗口的每次删一月delta均不低于-0.001。
- 先过准入，再查看Pareto关系；不以“未被支配”单独作为晋级理由。
- Pareto只比较同一seed、同一对照组、相同样本上的四项主cosine：另一候选四项都不差、至少一项更好，才构成支配。
- 月标准差、Q25、最差月和改善月份数分别保留为辅助证据，不合成另一个总分。
- 未覆盖完整主窗口时标为incomplete，不把缺失月份填成0分或自动通过。
- 基线行相对自身没有增益，passes_gates=False是预期行为，不表示否定基线。

这些规则对本次历史结果属于**事后审计**，不能冒称历史预注册，也不据此追溯撤销319特征已有决策。未来实验启动前冻结规则，看到结果后不放宽。
